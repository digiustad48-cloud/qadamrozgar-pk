How to Verify Gulf Job (Must Do):

  1. Ask employer for OEPL (Overseas Employment Promoter License) Number — format: OEPL-XXXX
  2. Go to https://beoe.gov.pk → List of OEPs
  3. Search license number — If not found, it's FRAUD
  4. Check office address — Visit physically if possible
  5. Never pay full fee upfront — BEOE allows max Rs. 6000-10000 service charge only

For Govt Jobs: Apply only on official portal: njp.gov.pk, fpsc.gov.pk, ppsc.gop.pk, etc. No fee via Easypaisa.

✅ Our Strict Filter blocks: "Earn daily", "WhatsApp only", "Typing work 50k", "Investment 500" — but scammers change wording, so YOU must verify.
